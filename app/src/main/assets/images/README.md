# Image Assets

Simpan aset gambar aplikasi di folder ini.

## QRIS Apotek Naufal

Letakkan gambar QRIS resmi dengan nama `qris-apotek-naufal.jpg` pada folder ini:

`app/src/main/assets/images/qris-apotek-naufal.jpg`

Pastikan gambar adalah file asli dari merchant. Jangan mengganti QRIS dengan placeholder atau membuat ulang kode QR karena kode harus tetap dapat dipindai.
